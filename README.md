# Personal Expense Analytics Project

## Project Overview

This project analyzes personal income and expense data using Python and visualizes important financial insights through graphs and dashboards.
It also predicts future expenses using Machine Learning techniques.

The project is built using:

* Pandas
* NumPy
* Matplotlib
* Scikit-learn
* Streamlit

---

# Features

* Data Cleaning and Preprocessing
* Financial Summary Analysis
* Category Wise Expense Visualization
* Monthly Expense Trend Analysis
* Payment Method Analysis
* Top 10 Highest Expenses Analysis
* Expense Distribution Pie Chart
* Advanced Dashboard Visualization
* Expense Prediction using Linear Regression
* Interactive Streamlit Dashboard
